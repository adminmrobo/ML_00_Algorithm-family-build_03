Three Chapters

三部曲 — 家谱、名册，还有会议

三部都按同样的顺序进行（全体 → 监督 → 无监督 → 强化 → 集成）。把相同序号的几集连起来看，就能以“家谱 → 名册 → 会议”（概念 → 技术 → 实战）的方式，三次遇见同一个家族。

House Rules

家族的规矩 — 摊牌与阅读方法

每块地盘一次摊牌

两股势力针对同一个问题选择不同的方法。点击“打开账本”之前，先猜猜谁会赢吧。结果由页面在浏览器中直接计算。

胜者并非注定

多疑的一方（果蝇）不会总赢，自信的一方（Money-Robo）也不会总赢。用“改变条件”按钮换一换数据，胜负有时会反转。做出判定的不是教父，而是数字。

Notes

设定与注意事项

  • 数据与计算. 各集的数据都是按规则生成的示例，并非真实记录（随机数种子固定）。摊牌结果和图表由各集页面在浏览器中直接计算。
  • 参考资料. 组织图的结构参考了 Machine Learning Algorithm Family Tree 信息图（Pooja Pawar）。没有搬用其图片，只参考了家族·派·算法之间的关系后重新绘制。
  • 图画. 人物和场景是为本系列绘制的图画。NPC 和家族纹章由本页面直接以像素绘制。
  • “教父”设定. 只借用了犯罪家族类作品的一般氛围。没有使用任何特定电影的人物、台词、标志或音乐，也不涉及暴力。“家族”是对一群算法的比喻。
  • 人物. Money-Robo 是作者所运营服务的吉祥物角色。博士、助手、果蝇研究员和 NPC 均不代表真实人物。台词中关于金钱·投资的说法只是口头禅，并非投资建议。
  • 语言. 本系列以韩语写成，并译为英语、中文、日语、乌兹别克语和俄语。Colab 代码的注释和运行结果保留韩语原文。
